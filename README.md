# Feminista — animation studies

Five studies for the House of Feminista. Open `index.html` for the gallery of cards.

1. **The Basalt Wall** (`wall.html`) — three bottles in lit basalt niches; hover for light, click to come closer.
2. **The Fusion** (`fusion.html`) — every note flies in, circles the bottle and fuses inside.
3. **The Stage** (`stage.html`) — one perfume at a time on a stone stage while the scene changes behind it.
4. **The Art of 180** (`site/art-of-180.html`) — one bottle on the real workbench; scroll through the five phases.
5. **The Website** (`site/index.html`) — the full demo site with the animated sections built in.

## Run locally

Serve the folder over HTTP (the 3D studies load modules and textures):

```
python -m http.server 5173
```

Then open http://localhost:5173/.
